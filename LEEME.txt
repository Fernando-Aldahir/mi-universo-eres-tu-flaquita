UNIVERSO 3D PARA FLAQUITA 💜

Archivos:
- index.html: página web
- assets/foto_1.png ... foto_7.png: imágenes extraídas del PDF
- assets/cancion.mp3: la canción que compartiste

IMPORTANTE:
La página usa Three.js desde internet, así que necesitas conexión para cargar la parte 3D.

Para abrirla localmente:
1. Descomprime toda la carpeta.
2. Si usas Visual Studio Code, abre la carpeta completa.
3. Instala la extensión "Live Server" si aún no la tienes.
4. Haz clic derecho en index.html y selecciona "Open with Live Server".

No muevas index.html fuera de la carpeta: necesita la carpeta assets para encontrar las fotos y la canción.
El navegador puede requerir que presiones "Nuestra canción" para comenzar el audio.
